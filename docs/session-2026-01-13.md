## Key Decisions

- **Enforcer → Hook:** Validation is deterministic (file exists, sections present), doesn't need LLM
- **Recorder → Session-end:** Within-session context preserved by Claude's memory; only need handoffs for cross-session
- **"Replaces X" comments:** Removed - cleaner to describe what code does, not what it replaced
- **Remove `check_command`:** Over-engineered abstraction that assumes all projects have one validation command. Replaced with:
  - `alto.verification` hooks for automated checks (typecheck, lint, test)
  - "How to Verify" section in tasks for conceptual acceptance criteria
- **alto-qa as test writer:** QA now writes tests, role agents only implement. Clean separation of concerns.
  - Pipeline: role agent → alto-qa (writes tests) → code-simplifier → gitops
- **Hook error handling:** All hooks now use `@safe_hook` decorator
  - Errors logged to `runs/errors.jsonl` instead of crashing Claude Code
  - Health check on session start reports setup issues
  - Graceful failure: hooks don't crash, just log and continue
- **Handoff pre-creation:** Orchestrator creates handoff template, agents just Edit
  - `current_handoff` field in state.json gives explicit path
  - Saves agent tokens on figuring out file paths/numbering
